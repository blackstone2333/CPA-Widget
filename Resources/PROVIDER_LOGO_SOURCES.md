# Provider logo sources

All assets below came from first-party provider domains on 2026-08-07. They are
included for provider identification only and retain the source artwork's colors.

| Asset catalog name | Source | Asset and rationale |
| --- | --- | --- |
| `CodexLogo` | <https://openai.com/codex> | `OpenAILogomark.svg` is the parent OpenAI logomark served inline by the official Codex page. The retrieved page did not expose a separately downloadable Codex product mark, so this is an explicitly documented parent-mark fallback. Its official `currentColor` vector is rendered as an adaptive template for light and dark widgets. |
| `AntigravityLogo` | <https://antigravity.google/> | `AntigravityLogo.png` is the distinct original-color product glyph linked by the official page as `/assets/image/antigravity-logo.png`. The page also exposes an inline SVG wordmark; the linked glyph is used here because this image set is intended for a compact provider badge. |
| `ClaudeLogo` | <https://claude.ai/favicon.svg> | `ClaudeLogo.svg` is Claude's official orange product mark, served directly by Anthropic's Claude domain. |
| `KimiLogo` | <https://www.kimi.com/> and <https://statics.moonshot.cn/kimi-web-seo/assets/kimi.icon-BhdvzFgS.js> | `KimiLogo.svg` preserves the `a_Kimi` vector path from the official Kimi web app's first-party Moonshot asset bundle. Its official `currentColor` vector is rendered as an adaptive template for light and dark widgets. |

The Codex and Antigravity source pages provide the exact official evidence used for
the fallback/selection decisions above. No third-party logo repository was used.
